## 🇬🇧 English Documentation

### 🚀 Vision & Academic Purpose
**C-Algorithm** is a native desktop visual programming environment designed to replace bulky, obsolete academic flowchart tools (like Flowgorithm) with modern game-engine node workflows (similar to Unreal Engine Blueprints) combined with international flowchart standards (ISO 5807).

While users design algorithm flowcharts visually, the engine simultaneously runs:
1. **Dual-Target Code Generation:** Convert visual schemas into clean, compilable **Modern C++17** (`std::cout`, STL, RAII) or pure **ANSI C (C99/C11)** (`stdio.h`, `printf`, `scanf`, `typedef struct`).
2. **Data Structure Advisor:** Real-time analysis of memory layout (Stack vs. Heap), cache locality, and asymptotic time complexity ($O(1)$, $O(N)$, $O(N \log N)$).
3. **Resilient Input Stream Guard:** Automatically injects stream shields preventing infinite loops when invalid input (e.g., text into integer `scanf`/`cin`) is supplied.

### 🌟 Key Engineering Highlights
- **Dual Language Target:** Switch seamlessly between `Convert to C++17` and `Convert to C`.
- **Standalone Portable Binary:** Packaged with `/MT` (Static C Runtime) into a single 1.2 MB executable `exe/C-Algorithm.exe`. Runs anywhere on Windows 10/11 from a USB drive without dependencies or installation.
- **Directional Cubic Bézier Cables:** Clear execution flow with socket pins (`•`) and sharp arrowheads (`▶`).
- **Dedicated Loop End Schema:** Clean execution graph modeling where loop bodies terminate into a `Loop End` node (`}`), continuing onward with standard sequential execution.
- **Eye-Friendly Themes:** Default *Dark Amethyst Night* (Deep neon purple `#1A0D2E`, lilac grid lines `#461C78`, teal borders `#0D9488`, and gold accents `#F59E0B`).

### 📐 Flowchart Architecture (ISO 5807 Standards)
- **Pill / Oval:** `Program Start (main)`, `Program End (return 0)`, and `Loop End (})`.
- **Parallelogram:** `Console Output (printf / cout)` and `Keyboard Input (scanf / cin)`.
- **Diamond:** `Branch Condition (if - else)` with dedicated True (Green) and False (Red) paths.
- **Hexagon:** `For Loop`, `While Loop`, `Do-While Loop` with single Body outlet.
- **Rectangle:** `Variables`, `Assignments`, `Math Operations`, `Structs`, `Arrays`, and `Data Structures`.

### 🛠️ Building from Source
Prerequisites: MSVC v143 (Visual Studio 2022 C++ Build Tools) on Windows 10/11.
```cmd
compile.bat
```
The compiled standalone binary is placed in `exe/C-Algorithm.exe`.

## 🇹🇷 Türkçe Dokümantasyon

### 🚀 Proje Vizyonu ve Amacı
**C-Algorithm**, algoritma öğrenen öğrencilerin ve yazılım mühendislerinin klasik, hantal akış şeması araçları yerine; modern oyun motoru düğüm mimarilerini ve uluslararası akış şeması standartlarını bir arada sunan **yerel bir C/C++ masaüstü geliştirme ortamıdır**. 

1. **Çift Hedefli Kod Üretimi:** Akış şemalarından anında **Modern C++17** veya saf **ANSI C (C99/C11)** kodu üretme.
2. **Veri Yapıları Danışmanı (Data Structure Advisor):** Bellek yerleşimi (Stack vs. Heap), önbellek isabet oranı ve Big-$O$ asimptotik karmaşıklığını canlı analiz etme.
3. **Akıllı Akış Güvenliği (Stream Shield):** Sayısal değişkenlere metin girildiğinde programın kilitlenmesini engelleyen otomatik `scanf`/`cin` kalkanı.
4. **Bağımsız Taşınabilir EXE (`exe/C-Algorithm.exe`):** `/MT` statik kütüphane bağlama sayesinde hiçbir kurulum veya ek DLL gerektirmeden flash bellekten çift tıklamayla çalışabilirlik.
