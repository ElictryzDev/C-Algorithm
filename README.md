# ⚡ C-Algorithm — Visual Scripting & Data Structure Advisor

> **Native Visual Algorithm & Data Structure Engineering IDE**  
> *Crafted in Modern C++17, DirectX 11, and Dear ImGui. Zero web technologies, 144 FPS GPU rendering.*

---

## 🚀 Proje Vizyonu

**C-Algorithm**, yazılımcıların ve mühendislik öğrencilerinin algoritmalarını görsel akış şemaları üzerinden tasarlayıp, arkasındaki bellek ve zaman karmaşıklığını ($O(1)$, $O(N)$) **Data Structure Advisor** ile gerçek zamanlı analiz eden ve doğrudan derlenebilir **temiz C++ kodu üreten** yeni nesil bir masaüstü IDE'sidir.

---

## 🌟 Öne Çıkan Özellikler

1. **🔒 Project Gating & .calg Dosya Formatı:**
   - Proje açılmadan veya oluşturulmadan arayüz kilitli kalır.
   - Projeler `.calg` formatında kaydedilebilir ve istenildiği zaman geri yüklenebilir.
2. **🧠 Data Structure Advisor:**
   - `std::vector`, `std::list`, `std::stack`, `std::queue`, `BinaryTree` yapılarının bellek yerleşimi ve işlem maliyetlerini analiz eder.
   - CPU darboğazlarını (Cache Miss, gereksiz kopyalama) ve taşma (Overflow) risklerini tespit eden akıllı teşhis kartları.
3. **⚡ Zengin Tip Sistemi (Rich Type System):**
   - `int`, `double`, `float`, `bool`, `long long`
   - Düşük seviyeli unsigned tipler: `uint8_t`, `uint16_t`, `uint32_t`, `uint64_t`
4. **💻 %100 Derlenebilir C++ Kod Üretimi:**
   - Akışta çizilen değişkenleri, `std::cout` çıktılarını ve işlemleri doğrudan bağımsız `main()` fonksiyonu olarak üretir.
